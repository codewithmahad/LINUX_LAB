# LINUX_LAB

> A long-term workspace for mastering Linux, Bash shell scripting, and command-line automation through continuous learning and hands-on practice.

---

## Overview

**LINUX_LAB** is a permanent workspace dedicated to developing practical proficiency with **Linux**, the command line, and **Bash shell scripting**.

The repository began alongside my Operating Systems studies, where Linux commands and shell scripting form an important part of the laboratory work. However, its purpose extends beyond university coursework.

It is designed as a long-term environment for learning how to work effectively with Linux systems, understand the command-line environment, write reliable shell scripts, automate repetitive tasks, and develop skills that remain useful throughout software engineering and backend development.

Rather than serving as a collection of isolated commands or scripts, this repository grows incrementally as concepts are studied, practiced, implemented, and revisited.

---

## Purpose

This repository exists to:

- Develop strong practical command-line skills in Linux.
- Build a structured understanding of Linux commands and utilities.
- Learn Bash shell scripting from fundamentals to practical automation.
- Practice working with files, permissions, processes, pipes, redirection, and system utilities.
- Develop scripts for automating repetitive development and system tasks.
- Connect Operating Systems concepts with their practical Linux environment.
- Maintain an organized reference for future revision and professional use.
- Continuously improve Linux proficiency through hands-on experimentation.
